03 · Pattern matching

Stripes, plaids, and repeats need more fabric than the plain yardage — every cut has to start at the same point in the repeat. Enter the repeat size and this works out the extra to order and how many repeats run down the piece.

❯ order with matching

16.5 yards
Plain yardage (54 in)13 yd
Matching allowance+3.3 yd
Repeats down the full length26

Rule behind the math: each panel can waste up to one full repeat where the cut starts. Bigger repeat = more waste per cut. When in doubt, order the extra half yard — a matched seam you can see is a callback waiting to happen. These percentages are ordering allowances, not a guarantee for a specific fabric — check the bolt width and repeat on the actual fabric before you cut.

Reupholster, or tell them to buy new?

Recommend reupholstering when…

  • It's an heirloom, an antique, or has sentimental value
  • The frame is solid, handcrafted wood — built to last
  • The client wants full customisation
  • Your estimate beats new furniture + delivery + assembly
  • It's an expensive piece (e.g. a La-Z-Boy with remote)
  • Fabric or padding is worn, pet-damaged, or holds stains, smoke, or mildew odours
  • The style is dated but the structure is good

Recommend buying new when…

  • The original piece was cheap or low-quality
  • There's no sentimental value
  • The frame is poorly built or structurally damaged
  • The client's budget is limited
  • The piece is the wrong size for their space
  • The client dislikes the style entirely
